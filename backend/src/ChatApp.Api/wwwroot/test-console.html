ChatApp — Bảng test thủ công (không cần terminal)

Trang này chỉ dùng để kiểm thử. Mở bằng trình duyệt khi backend đang chạy (địa chỉ hiện tại: ).

1. Đăng nhập lấy JWT

2. Test các API còn lại (tạo conversation, đổi tên, tóm tắt, ...)

Dùng giao diện Scalar — dán JWT ở mục 1 vào nút Authorize (scheme Bearer), rồi gọi endpoint bất kỳ trực tiếp trên trang, không cần Postman/curl.

→ Mở Scalar API tester

3. Test tin nhắn/ảnh realtime (SignalR — Scalar không test được phần này)

Chưa kết nối

4. Tạo user test qua Supabase Studio (không cần API)

Studio → Authentication → Users → nút Add user → chọn Create new user. Nhớ tick Auto Confirm User để đăng nhập được ngay, không cần xác nhận email.

Muốn set username hiển thị cho đúng: điền vào ô "User Metadata" dạng JSON: {"username":"alice"}.
